# Выполненные проверки

Проект подготовлен 27 октября 2026 года.

## Что действительно проверено

- Локальное окружение Windows, CPU: Python 3.12.14, PyTorch 2.14.1+cpu, Torchvision 0.29.1+cpu, NumPy 2.5.2, Pillow 12.3.0, Matplotlib 3.11.2, scikit-learn 1.9.1 и pytest 9.1.1.
- Команда `python -m pytest -q`: **11 тестов пройдено за 31,70 секунды** при первоначальной подготовке проекта.
- Стратифицированное разделение: отсутствие пересечения, полное покрытие примеров, баланс классов и воспроизводимость.
- Порядок меток EMNIST, исправление ориентации и отсутствие случайных преобразований при валидации.
- Подготовка пользовательского изображения: полярность, размер 28×28 и отклонение пустого входа.
- Реальное обновление весов на синтетических тензорах, сохранение и загрузка лучшей модели, распознавание с top-k=1 и отклонение недопустимого top-k.
- Управляемый сценарий ранней остановки: сохранена лучшая эпоха, обучение завершено после заданного числа эпох без улучшения.
- Количества в матрице ошибок, macro F1 и создание PNG на синтетических метках.
- Полный цикл публичных команд на временных **синтетических файлах MNIST в формате IDX**: обучение, графики, оценка и распознавание. Датасет не скачивался.
- Три ноутбука проверены по формату nbformat; во всех опубликованных ноутбуках отсутствуют выполненные выводы.
- Число параметров модели сопоставлено с восстановленной архитектурой учебной работы.
- Проверен синтаксис всех Python-файлов. Поиск по характерным шаблонам не обнаружил учётных данных, приватных ссылок Drive или абсолютных путей пользователя в публикуемых текстах. Это не формальный аудит безопасности.

Первый запуск GitHub Actions для версии с кодом также завершился успешно. Текущий статус доступен во вкладке Actions репозитория. Структура Colab-ноутбука проверена, но в сессии Colab он не выполнялся.

## Что не выполнялось

Полное обучение на EMNIST/MNIST, измерение новых метрик на тесте, исследование гиперпараметров, проверка GPU и оценка точности на реальных пользовательских изображениях не проводились.

Синтетические проверки подтверждают работоспособность отдельных действий и полного цикла, но не качество распознавания. Исторические метрики прочитаны из сохранённых выводов учебных ноутбуков и независимо не воспроизводились.
