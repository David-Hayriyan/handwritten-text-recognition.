# Распознавание своего символа

Подготовьте изображение одного отдельно написанного символа в обычной ориентации на однотонном фоне. Обрежьте соседние надписи, границы листа и тени. Сохраните файл вне репозитория, например как `../my-character.png`.

После обучения выполните:

```bash
python -m htr.predict --checkpoint runs/emnist-baseline/best.pt --image ../my-character.png --top-k 5 --save-preprocessed runs/my-character-28x28.png
```

Если ответ неверный, проверьте сохранённое изображение 28×28. Для тёмных чернил на белой бумаге используйте `--polarity dark-on-light`, для светлого символа на чёрном фоне — `--polarity light-on-dark`.

Команда выводит JSON с индексами классов, символами и оценками softmax. Пример готового предсказания здесь не приведён, поскольку переработанная модель ещё не обучалась на EMNIST. Значения softmax не являются откалиброванной уверенностью в правильности ответа.
